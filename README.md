# Mehedi Engineering Survival

A 2D engineering survival and puzzle adventure game developed with Python and Pygame.

## About

Mehedi Engineering Survival is an educational adventure game where the player takes the role of an engineering specialist trapped inside a laboratory.

The player must inspect equipment, solve engineering problems, repair electrical systems, obtain the laboratory keycard, shut down the laboratory system, and finally escape to the university campus.

## Features

* Fullscreen Pygame interface
* Character selection
* Engineering based puzzles
* Laboratory exploration
* Power room and control room
* Health and energy systems
* Machine temperature system
* Security drone AI
* Environmental hazards
* Inventory system
* Mission objectives
* Save and load system
* Animated player
* Animated security drone
* Background music and sound effects
* University campus escape sequence

## Engineering Challenges

The game includes practical engineering calculations involving:

* Electrical power
* Voltage
* Current
* Resistance
* Battery energy
* Generator systems
* Circuit breakers
* Motor systems

## Technology

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Mehedi-Engineering-Survival.git
```

Enter the project directory:

```bash
cd Mehedi-Engineering-Survival
```

Install the required package:

```bash
pip install -r requirements.txt
```

Run the game:

```bash
python main.py
```
